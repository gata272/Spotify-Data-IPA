# Spotify統計（SpotifyStats）

Spotifyの「拡張ストリーミング履歴」zipを読み込んで、期間を指定してアーティスト・曲ごとの再生回数／再生時間ランキングや、月ごと・日ごと・時間帯ごと・曜日ごとの統計を見るためのiPhoneアプリです。GitHub Pages版（Spotify再生履歴ランキング）をIPA化し、アプリならではの機能を追加しました。

## 使い方

1. Spotifyの「アカウント」→「プライバシー設定」→「データをダウンロードする」で「拡張ストリーミング履歴」をリクエストし、届いたzipを用意します
2. アプリの最初の画面（またはホーム下部の「データ」→「追加で読み込む」）からzipを選びます。JSONファイル単体でも読み込めます
3. ホームで期間（プリセット／日付指定）と条件（30秒未満を除く、ポッドキャストを含める）を選ぶと、ランキング／グラフ／アーティスト別統計が切り替わります

## Web版から引き継いだ機能

- 期間プリセット（全期間／直近30日・3か月・6か月・1年／今年／年別）と日付の直接指定
- サマリー（総再生時間・総再生回数・アーティスト数・曲数、1日平均つき）
- ランキング：アーティスト／曲 × 再生回数順／再生時間順、名前検索、もっと見る
- アーティスト詳細：曲ランキング、ミニ統計（全体に占める割合・アルバム数・初回再生）、ハイライト、月ごと・日ごと・時間帯ごとのグラフ
- ハイライト：いちばん聴いた日、よく聴く時間帯、いちばん聴く曜日、連続で聴いた最長記録、期間内に初めて聴いた曲数、リピート率
- 月ごと・日ごと（並び替え＆リストつき）・時間帯ごとのグラフ。グラフはタップすると値が大きく表示されます

## IPA版で追加した機能

- **データ保持**：読み込んだ履歴はアプリ内に保存され、次回起動時もそのまま見られます（Web版はページを閉じると消えていました）
- **追加読み込み＆重複除去**：新しいzipをそのまま読み直しても、同じ再生は二重に数えられません。少しずつ履歴が増える使い方にも対応します
- **曜日ごとの再生時間グラフ**を追加
- **前期間との比較**：選択した期間と、その直前の同じ日数の期間で、総再生時間・総再生回数・トップアーティストを比較します
- **まとめカードの画像シェア**：期間のトップアーティスト／トップ曲／総再生時間を1枚の画像（Wrapped風）にして共有できます
- ハイライトに「深夜（0〜4時）の再生割合」「トップアーティスト集中度」を追加

## ビルド方法（PC不要）

1. GHUploader で新しいリポジトリ（例：`SpotifyStats`）を作成し、このZIPの中身をアップロードします（`.github` フォルダも含めてください）
2. GitHub Actions（macos-26）が未署名IPAをビルドします
3. 成果物 `SpotifyStats-ipa` をダウンロードし、LiveContainer にインポートしてください

## 注意

- 再生履歴のzip／JSONそのものはリポジトリに含めないでください（公開リポジトリだと再生履歴が公開されてしまいます）。このアプリのリポジトリにはソースだけを置いてください
- データは端末内だけで処理・保存され、外部に送信されることはありません
